// HOW CAN I HELP

想学习摄影构图评析、调色修图、无人机安全起飞或 Vibe Coding 个人建站？欢迎随时通过邮件向我提问交流。

结合我积累的摄影、航拍与数字创作经验，我主要为大家提供 3 项线上指导：① 摄影与后期修图线上指导（构图评析 + 曝光参数答疑 + Lightroom 调色示范）；② 无人机航拍与安全飞行线上指导（适飞空域申报查询 + 起飞安全参数设置 + 航拍运镜与后期分享）；③ Vibe Coding 个人建站指导（如何用 Figma + AI 将设计稿变成可交互网页并部署）。

当然可以！摄影的核心在于观察视角、光线捕捉与构图逻辑，而非昂贵的器材。无论是 iPhone 还是安卓手机，只要你想提升照片通透感、学习冷暖色调搭配或掌握手机端调色，都可以随时把照片发给我交流。

新手最常见的问题是起飞慌乱和环境误判。我会在线上带你理清飞行前检查清单：① UOM 实名登记与禁飞区合规查询；② 返航高度与避障动作的关键安全阈值；③ 循序渐进的视距内悬停、刷圈与运镜练习方法，帮助你建立安全飞行信心。

只需点击左侧的「发邮件提问」发送邮件到 shawnfeng@moonshotacademy.cn 即可。提问时建议附上：① 你的照片原片（或无人机/建站疑问截图）；② 拍摄设备或当前遇到的具体卡点；③ 你希望达到的效果。我会在周末抽出时间认真查看并提供针对性建议与示范。

我从初中开始系统投入摄影与无人机航拍，专注城市天际线、蓝调夜景与极简构图，独立拍摄了北京、郑州、西安、重庆等城市的多组视觉专题。同时，我结合 AI 与现代前端技术（Vibe Coding）独立设计并开发了这个个人作品集网站。
