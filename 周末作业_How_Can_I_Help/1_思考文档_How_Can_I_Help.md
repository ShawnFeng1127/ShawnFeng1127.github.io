## 一、 我想出的三种可以提供的帮助（3 Ways I Can Help）

个人网站除了展示“我是谁、我拍过什么作品”，更应该成为连接同学与朋友的窗口。结合我日常积累的摄影、航拍与数字创作经验，我想出了 **3 种** 可以通过**提供线上指导与经验分享**为大家提供的帮助：

1. **【帮助一 · 重点展开】摄影与后期调色线上指导**（线上看片构图评析 + 曝光参数答疑 + Lightroom 修图指导）
2. **【帮助二 · 重点展开】无人机航拍与安全飞行线上指导**（空域申报与选购线上指导 + 起飞安全参数设置 + 航拍构图与后期分享）
3. **【帮助三 · 补充分享】Vibe Coding 个人建站线上指导**（线上指导如何用 Figma + AI 编写结构化提示词，把设计稿变成可交互网页并部署到 GitHub Pages）
